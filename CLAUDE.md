# ΒybAi

Окно рядом с терминалом: схема проекта, на которой видно, с чем агент работает прямо сейчас. Поддерживаются Claude Code и Codex CLI.

Сначала прочитай `STATUS.md`: там текущее состояние, что проверено и что делать дальше.

## Что читать

- `STATUS.md` — где остановились.
- `docs/architecture.md` — устройство приложения и поток данных.
- `docs/map.md` — формат схемы `.bybai/map.json`, раскладка и живая подсветка.
- `docs/events.md` — хуки агентов и как они превращаются в состояние.
- `design/reference.png`, `design/focus.png` — как выглядит окно. `design/tokens.css` и `design/components.css` — единственный источник стилей, приложение подключает их напрямую.

## Правила продукта

- Название **ΒybAi**, первый символ — греческая заглавная бета. В коде, командах и именах файлов используй `bybai`.
- Главное на экране — холст со схемой. Текст появляется по запросу: в карточке узла, в списке плана, в подсказках. Не добавляй постоянных панелей с текстом.
- Схему рисует агент по запросу человека и пишет в `.bybai/map.json` в папке проекта. Это единственное, на что ΒybAi тратит токены агента. Навыка, MCP-сервера и постоянных инструкций в настройках агента нет.
- Живая подсветка бесплатна: слушатель отвечает на хуки пустым ответом. Любое изменение, из-за которого агенту уходит хоть байт, сначала согласуй с владельцем и отрази в счётчиках нижней строки.
- Интерфейс только показывает. Управление агентом остаётся в его CLI.
- Хуки в настройках агентов существуют, только пока приложение открыто: при запуске ставятся, при выходе убираются. Чужие хуки и остальные настройки не трогаются.
- Цвет состояния один на всё приложение: лаймовый — агент работает здесь сейчас, красный — ошибка, оранжевый — агент ждёт человека. Цвет роли узла живёт только в значке. Состояние всегда продублировано меткой.
- Значки свои, в `src/map/icons.tsx`. Чужие наборы значков и логотипы продуктов не подключай.
- Новые цвета и кегли сначала добавляются в `design/tokens.css`.
- Смену логики продукта или вида экрана согласуй с владельцем. Решения по реализации принимай сам. Перед большой переделкой экрана сначала покажи владельцу кадр.

## Команды

```
npm test                              тесты модели и схемы
npm run build                         проверка типов и сборка интерфейса
npm run tauri dev                     окно приложения в режиме разработки
npm run tauri build -- --no-bundle    готовый exe в src-tauri/target/release
npm run replay -- fixtures/receipt-bot.jsonl --speed 4    демо в открытое окно
```

Rust в новом терминале может не найтись: добавь `%USERPROFILE%\.cargo\bin` в PATH.

Переменная окружения `BYBAI_HOME` подменяет домашний каталог. Запускай окно с ней, когда проверяешь кнопки подключения: тогда настоящие `~/.claude` и `~/.codex` не затрагиваются.

## Определение готовности

Изменение разбора хуков или схемы покрыто тестом. Контрольный кадр (первые 31 хук записи `fixtures/receipt-bot.jsonl`) совпадает с `design/reference.png`. `npm test`, `npm run build` и `cargo test` проходят.
