# ΒybAi

Окно рядом с терминалом, которое показывает, что агент запланировал и что он делает прямо сейчас. Поддерживаются Claude Code и Codex CLI. Приложение только слушает: оно ничего не возвращает агенту и не добавляет токенов в его контекст.

## Что читать

- `docs/architecture.md` — устройство приложения и поток данных.
- `docs/events.md` — что приходит от агентов и как это превращается в состояние экрана.
- `design/reference.png` и `design/states.png` — согласованный вид. `design/tokens.css` и `design/components.css` — единственный источник стилей, приложение подключает их напрямую.

## Правила продукта

- Название **ΒybAi**, первый символ — греческая заглавная бета. В коде, командах и именах файлов используй `bybai`.
- Ноль токенов. Слушатель отвечает на каждый хук пустым ответом. Любое изменение, из-за которого агенту уходит хоть байт (ответ на хук, MCP-инструмент, инструкция в его настройках), сначала согласуй с владельцем и отрази в счётчике «ΒybAi → агенту».
- Интерфейс только показывает. Управление агентом остаётся в его CLI.
- Хуки в настройках агентов существуют, только пока приложение открыто: при запуске ставятся, при выходе убираются. Чужие хуки и остальные настройки не трогаются.
- Экран: тёмная полоса с сессиями; слева задача и шаги с цепочками действий слева направо; справа план и изменённые файлы; снизу текущее действие и счётчик токенов.
- Цвет значит состояние и больше ничего: синий — идёт, красный — ошибка, терракота — агент ждёт человека. Цвет всегда продублирован знаком или словом.
- Новые цвета и кегли сначала добавляются в `design/tokens.css`.
- Смену логики продукта или геометрии экрана согласуй с владельцем. Решения по реализации принимай сам.

## Команды

```
npm test                              тесты модели
npm run build                         проверка типов и сборка интерфейса
npm run tauri dev                     окно приложения в режиме разработки
npm run tauri build -- --no-bundle    готовый exe в src-tauri/target/release
```

Демо без агентов: открыть окно и выполнить `npm run replay -- fixtures/demo.jsonl --speed 4`. То же в браузере без окна: `npm run bridge`, `npm run dev`, открыть `http://127.0.0.1:5173` и запустить ту же команду.

Переменная окружения `BYBAI_HOME` подменяет домашний каталог. Запускай окно с ней, когда проверяешь кнопки подключения: тогда настоящие `~/.claude` и `~/.codex` не затрагиваются.

## Определение готовности

Изменение разбора событий покрыто тестом на записи `fixtures/demo.jsonl` или на отдельном теле хука. Контрольный кадр (первые 48 хуков записи) совпадает с `design/reference.png`. `npm test` и `npm run build` проходят.
