# ΒybAi · состояние на 27 ноября 2026

Файл для быстрого старта следующей сессии: что сделано, что проверено, что осталось.

## Что это сейчас

Окно на Tauri. Агент по запросу человека записывает схему архитектуры проекта в `.bybai/map.json`; окно рисует её на тёмном холсте и подсвечивает узлы, с которыми агент работает прямо сейчас. Подсветка идёт через хуки Claude Code и Codex и не стоит токенов. Образец по функционалу — открытый проект archify; движок, формат и значки свои.

- Репозиторий: эта папка, ветка `main`. На GitHub ничего не отправлялось.
- Готовый exe: `src-tauri\target\release\bybai.exe` (около 3,3 МБ). Папка `target` в git не входит; пересборка — `npm run tauri build -- --no-bundle`.
- Как выглядит: `design/reference.png` (обычный вид) и `design/focus.png` (фокус на узле и трассировка).

## Как попробовать

1. Запустить `src-tauri\target\release\bybai.exe`.
2. Демо без агента: в терминале в этой папке `npm run replay -- fixtures/receipt-bot.jsonl --speed 4`.
3. С настоящим агентом: включить `claude` в верхней полосе, начать сессию Claude Code в папке любого проекта, нажать в окне «Скопировать запрос для агента» и вставить запрос агенту.

## Решения владельца

- Ядро: схема от агента плюс живая подсветка. Текстовая лента действий отвергнута: «слишком много текста и визуально неприятно».
- Свой движок с выбранным набором, а не код archify. Значки свои.
- В первой версии один тип схемы: архитектура.
- Тёмный холст.
- Отдельное окно на Tauri, а не вкладка браузера.
- Агенты: Claude Code и Codex CLI.
- Расход токенов агента должен быть минимальным и видимым в окне.

## Что не проверено

- **Codex вживую.** Разбор его хуков написан по исходникам Codex 0.172 и проверен на синтетических телах. Ни одной настоящей сессии Codex с хуками не было. Неизвестно, как выглядит ответ команды с ненулевым кодом и сохраняется ли доверие к хукам после снятия и повторной установки.
- **Claude Code в интерактивном режиме.** Проверен только `claude -p`. Запрос разрешения и переход узла в «ждёт человека» вживую не наблюдались.
- **В окне не нажимались:** кнопка копирования запроса, поиск, «поверх окон», включение агентов в последней сборке.
- **Раскладка слева направо** проверена тестом, но не глазами: демосхема встаёт сверху вниз.
- **Узкое окно** для нового экрана не смотрелось.
- **Установщик NSIS** не собирался.

## Известные слабые места

- Отклонённый вызов инструмента не присылает завершения. Узел перестаёт светиться, когда агент начинает следующее действие; до этого он выглядит работающим.
- Связь через несколько рангов в другую группу может пройти поверх чужого узла.
- Вкладок сессий держится не больше восьми; каждый запуск `claude -p` создаёт новую.
- Схема не обновляется сама, а счётчик «вне схемы» только намекает, что она устарела.
